# 超級象棋 · 大盤暗棋

手機優先的網頁象棋變體：8×9 大盤暗棋，所有棋子互吃、可暗吃，兵可騎上馬／象／車並射箭。支援雙人同機對戰與電腦 AI（簡單／普通／困難）。

直接開啟 `index.html` 即可遊玩，無需安裝。

## 規則摘要
- 棋盤 8 × 9 共 72 格，棋子在格子裡；開局 32 顆蓋著，間隔一格錯落擺放。
- 每回合：翻一顆、走一步、吃一顆，或騎兵射一箭。第一個翻棋的人翻到的顏色就是他的陣營。
- 沒有大小，任何棋子都能吃敵方任何棋子；可暗吃蓋著的棋。
- 帥：直線 1～2 格｜仕：斜線不限格數｜相：田（塞象眼）｜俥：直線｜傌：日（拐馬腳）｜炮：走 1 格，隔一子吃｜兵：直線 1 格
- 兵騎傌／騎俥：射周圍 1 格；兵騎相：射周圍 2 格，射完休息一回合。箭不被擋、可射暗棋。
- 吃光對方獲勝；連續 50 回合沒有翻棋或吃子判和。
